# Логотип UMIT

Положите существующий логотип в эту папку под именем **logo.png**.

Рабочий путь на этом компьютере:

```text
C:\Dev\ticket-mvp\mobile\assets\logo.png
```

Подойдёт квадратное PNG, желательно с прозрачным фоном и размером 512×512
или больше. Логотип не нужно перерисовывать или вставлять в QML.
После добавления файла нажмите Run CMake, затем соберите APK заново.
CMake включит его в приложение как `qrc:/branding/logo.png` и использует
тот же PNG как значок запуска Android.
Пока файла нет, в шапке отображается буква U.

В текущем APK файла логотипа ещё нет, поэтому значок запуска Android стандартный.
